# Biodiversity Analyzer

Python script that calculates biodiversity indices from species observations.

## Indices calculated
- Shannon diversity index
- Simpson index
- Pielou evenness index

## Input
A `.txt` file containing one species per line.

Example:
Phrygilus gayi
Phrygilus gayi

Troglodytes musculus
Troglodytes musculus
Troglodytes musculus

Falco sparverius
